# Demonstration flow

Use fictional data and keep the video under five minutes if required by the event rules.

1. Open the sample planner. Explain the INR 6,400 starting balance, INR 150 daily essentials, rent, travel and expected allowance.
2. Compare the INR 2,000 purchase: the first shortfall is 8 November and the lowest balance is INR -950. Change the purchase to INR 500: the minimum becomes INR 550.
3. Test a three-day income delay. With the INR 2,000 purchase, minimum balance becomes INR -1,250. Explain that expected income is an assumption.
4. Load the fictional CSV. Preview seven rows with one duplicate excluded. Run local AI categorization, inspect uncertainty and evidence words, then correct a category or amount. Save six rows and show separate spending, refunds, income and transfers. Explain why history does not deduct money from the opening balance again.
5. If a Gemini key has been configured and a live request has been verified, request an explanation with consent and show the referenced calculated evidence. If it is unavailable, say so plainly; do not describe deterministic text or mock responses as live AI.
6. Show the source repository, tests, synthetic model evaluation and documented limitations. The product is a student decision aid, not a bank connection or investment adviser.

The private review uses an owner-only session key held in tab memory. Before an external judging deployment, configure a server runtime key and choose the intended site audience explicitly.
